# Taş-Kağıt-Makas

Python öğrenme sürecimde CLI Araçları Serisi'nin ikinci projesi. Kullanıcı ile bilgisayar arasında taş-kağıt-makas oyunu.

## Özellikler
- Bilgisayarın rastgele seçim yapması (`random.choice()`)
- Tekrar oynanabilir oyun döngüsü (`while` + `break` + `continue`)
- Skor takibi
- Geçersiz girdi kontrolü (input validation)

## Öğrendiklerim
- `random` modülü
- `while True` döngüsü ve `continue` ile tur atlama
- Sözlük kullanarak tekrarlayan if/elif mantığını azaltma
- `KeyError` ve neden oluştuğu
- f-string ile string formatlama

## Çalıştırma
\`\`\`
python tas-kagit-makasa.py
\`\`\`
